Preguntas frecuentes
¿Sirve cualquier ECU donante?

No. Se revisan referencias, hardware y compatibilidad antes de realizar la transferencia.

¿Necesitáis el vehículo?

En muchos casos el trabajo puede realizarse por envío con las dos unidades y los datos técnicos solicitados.

¿Qué ocurre si la original no se puede leer?

Se evalúa el estado de memorias y las posibilidades reales de recuperación antes de confirmar el procedimiento.

¿La donante queda lista para montar?

El objetivo del servicio es devolver la unidad preparada según el alcance técnico confirmado para ese sistema.
